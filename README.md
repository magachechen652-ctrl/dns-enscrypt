# DNS Encrypt — Android

Простое приложение с одной кнопкой: **«Шифровать»** поднимает локальный DNS-туннель и заворачивает весь системный DNS в **DNS-over-HTTPS (DoH)**.

## Что именно шифруется

Только DNS-слой — то, что обычно утекает в открытом виде в кафе, аэропортах и публичных Wi-Fi. Payload обычного трафика (HTTPS-сайты) уже зашифрован TLS на уровне приложения; это приложение закрывает **метаданные**: какие домены ты резолвишь.

Полный туннель всего трафика без VPN-сервера невозможен: зашифрованному потоку нужно куда-то terminating. Здесь terminating-точка — публичный DoH-резолвер (AdGuard по умолчанию).

## Архитектура

- `VpnService` создаёт TUN-интерфейс.
- В туннель заворачивается **только DNS** (split-tunnel: `addRoute` на фейковый DNS-IP `10.0.0.1`).
- Приложение читает IP/UDP-пакеты, вытаскивает DNS-запрос, отправляет его через **HTTPS POST** (`application/dns-message`) на выбранный резолвер.
- Ответ упаковывается обратно в IP/UDP и пишется в TUN.
- **Kill-switch**: если DoH не ответил — возвращается `SERVFAIL`, plaintext-DNS наружу не уходит.

## Резолверы

- AdGuard — режет рекламу и трекеры (по умолчанию)
- Cloudflare
- Google
- Quad9 — блокирует malicious-домены

## Ограничения

- DNS over **TCP** (port 53/TCP) не перехватывается — только UDP. Большинство запросов идут по UDP.
- IPv6-DNS не перехватывается: фейковый DNS — IPv4.
- Приложения с **захардкоженным** DNS-сервером (например, свой `8.8.8.8` внутри) могут обойти туннель. Системный резолвер — перехватывается.
- Bootstrap-запрос для самого домена DoH-сервера (`dns.adguard-dns.com`) идёт через системный DNS один раз. Это не утечка твоих запросов, но сам факт обращения к резолверу виден.
- Android разрешает только **один** активный VPN. Если уже работает другой VPN — это приложение не запустится.

## Сборка

1. Открой папку в Android Studio.
2. Дай Gradle синхронизироваться.
3. Запусти на устройстве (minSdk 26, Android 8+).
4. Нажми «Шифровать», разреши VPN-подключение.

## Файлы

- `DnsVpnService.kt` — TUN, чтение/запись пакетов, lifecycle.
- `DnsPacket.kt` — парсинг IPv4/UDP/DNS, сборка ответа, checksums.
- `DohResolver.kt` — OkHttp POST DoH.
- `MainActivity.kt` — UI, разрешение VPN, лог.
- `Resolver.kt` — список резолверов.
